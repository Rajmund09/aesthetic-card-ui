# Aesthetic Card UI

A simple and elegant card component built using **HTML and CSS**.  
This project focuses on clean layout, soft colors, and a calm visual feel, making it ideal for profile cards, blog previews, or content highlights.

## ✨ Features
- Minimal and modern card design
- Responsive layout using Flexbox
- Rounded corners and subtle shadows
- Tag-style labels and call-to-action button
- Clean typography and spacing optimize 

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, shadows, border-radius)

## 📸 Preview
A single card layout with an image, tags, title, description, and a button — designed to feel calm, simple, and readable.

## 🎯 Purpose
This project was created during my learning phase to practice:
- Card-based UI design
- CSS styling fundamentals
- Layout and spacing control
- Clean and readable HTML structure

## 🚀 How to Use
1. Clone the repository
2. Open the `index.html` file in your browser
3. Replace the image and text with your own content
